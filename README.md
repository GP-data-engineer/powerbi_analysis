# Energy Cost Analysis – Power BI Project

A simple analytical project built in Power BI using sample invoice data.
The goal is to simulate a typical operational analytics task: validating invoice data, identifying anomalies, and preparing visual insights.

## Features
- Import and cleaning of invoice data (CSV)
- Monthly cost and consumption analysis
- Cost per kWh calculation
- Detection of anomalies (unexpected spikes)
- Interactive dashboard

## Tools
- Power BI Desktop
- Excel (data preparation)

## Use case
This project reflects real tasks in operational analytics roles:
- verifying invoice correctness
- detecting anomalies
- preparing data for reporting
- building simple dashboards
